# M03：工具注册与六个基础工具

## 范围

本阶段把 M02 的一次性 FixtureExecutor 替换为可扩展工具层。Runner 没有为任何具体工具修改；
ToolRegistry 继续满足同一个 ToolExecutor 接口。实现 read_file、write_file、edit_file、glob、
search 和 shell，全部通过 Fake Provider 与临时目录验收。

每个工具拥有独立实现模块；文件读取/写入策略集中在 `file_common.py`，发现类工具的模式校验与
遍历集中在 `discovery_common.py`，默认工具集合只由 `factory.py` 组装。共享策略可以复用，
工具类之间不直接依赖，后续复杂化时可以独立修改单个工具。

没有实现真实模型、权限审批、安全沙箱、原子文件写入、外部修改冲突检测或任意后代进程树清理。

## 契约与数据流

```text
ToolCall
  → ToolRegistry 按名称查找
  → 对应 Pydantic arguments_model 校验
  → 工具级 timeout
  → Tool.run(已校验参数)
  → str 或 ToolOutput
  → 配对 ToolResult
```

ToolSpec 从工具实际使用的 arguments_model 生成 JSON Schema，并声明名称、描述、影响类型、
保守资源、默认超时和取消能力。注册时构建一次 ToolSpec，因此非法名称、Schema 或超时不会延迟到
首次模型调用才暴露。重复名称被拒绝，防止导入顺序静默替换实现。

参数错误和 ToolFailure 转为 is_error 结果并保留 call_id；未知工具同样反馈给模型。
未预期的 Python 异常继续交给 Runner 转为 tool_exception。ToolOutput 用于 Shell 非零退出等
“需要保留 stdout/stderr 正文，同时标记失败”的情况。

## 工作区与文件边界

Workspace 只接受相对路径，拒绝空路径、绝对路径、父目录片段和任意符号链接分量，最终解析结果还要
再次确认位于根目录。读、写、编辑、glob 和 search 共享这一实现。

read_file 有调用级字节上限，区分普通文本、超限、NUL 二进制和非法 UTF-8。write_file 限制
UTF-8 字节数且不隐式创建父目录。edit_file 要求 old_text 恰好出现一次；零匹配和多匹配都在写入前
失败并保持原文件不变。M03 直接写入文件，M04 将加入临时文件替换、内容哈希前置条件和竞态保护。

glob 稳定排序并限制结果数量，默认排除版本库与常见缓存。search 只搜索有界 UTF-8 普通文件，
限制文件大小、结果数量、单行长度和总输出，无法读取的文件以计数汇总。

## Shell 生命周期

Shell 使用 asyncio 子进程，从 Workspace 根目录启动，分别持续排空 stdout 和 stderr，最多保留配置的
前 N 字节并标记截断。非零退出保留两路输出且返回 is_error。工具超时通过取消 run 协程触发清理；
外部 Runner 取消沿同一路径传播。M03 只保证终止并 wait 当前 Shell 进程。Shell 可能启动后代进程，
其进程组、跨平台信号和完整清理由 M04 实现，因此当前能力不是沙箱，也不能用于不可信命令。

## 关键失败场景

| 场景 | 行为与副作用 |
| --- | --- |
| 缺字段、未知字段或错误类型 | invalid_arguments；工具 run 不会执行 |
| 未注册名称 | unknown_tool；Runner 可把结果反馈给模型 |
| 绝对、父目录或符号链接路径 | invalid_path；工作区内外文件均不修改 |
| 二进制、非法 UTF-8、超大文件 | 返回不同错误，读取保持有界 |
| edit_file 零匹配或多匹配 | ambiguous_edit；原字节保持不变 |
| 搜索结果过多 | 停止收集并返回截断标记 |
| Shell 非零退出 | 保留退出码和两路输出，is_error=true |
| Shell 超时或外部取消 | 取消读管道任务，kill/wait 当前进程 |

uv run --locked ruff format --check .

当前 Linux/Python 3.14.7 环境中 88 项测试通过，五个演示场景通过。happy 场景依次调用全部六个
基础工具并运行真实 unittest；其余轨迹覆盖参数错误、路径逃逸、编辑歧义和二进制文件。
Shell 超时及输出截断由单元测试验证。没有运行 Windows/macOS、多 Python 版本、真实模型或容器隔离。
