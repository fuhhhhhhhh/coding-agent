# B1：可靠执行与持久会话基础

状态：已规划、待实现；2026-10-15（Asia/Shanghai）。本文件是下一轮完整开发范围，不是功能通过证据。

## 一轮交付的目标

用户从同一 `codepilot` 产品入口连续完成任务，Shell 输出即使预览被截断仍能找回；正常退出重启后，会话消息、工具结果和日志引用仍可查看、继续追问。取消与崩溃必须留下可核对状态；副作用不明时停止协调，不自动重放。

B1 同时交付：取消清理修复、Shell/Local argv/Docker 截断前流式输出、输出与会话配额、版本化持久存储、连续对话、会话列表/查看/重开、工作区及遗留资源检查。内部按依赖实现与提交，不拆成多轮小点交付。

本阶段保留默认当前目录直接工作、非 Git 与脏目录兼容、显式 worktree、原生 Shell Git 以及既有审批链。网络/秘密 Action、完整磁盘硬配额、第二协议、MCP、PTY、多 Agent 归后续大阶段；这些边界不妨碍 B1 完整交付，但必须清楚展示现有能力差异。

## 入口与联合产品链

继续使用 `codepilot`、`codepilot run`。新增会话管理入口至少包含 `codepilot sessions list`、`codepilot sessions show <id>`、`codepilot resume <id>`；它们是待实现命令，不能当成现有功能。交互提示符采用同一会话服务，不再为每条输入丢弃历史。`run` 支持选择既有会话，参数在实现时固定并由安装版 --help 验收。

```text
CLI / 会话重开
  -> 校验配置、工作区身份及会话写锁
  -> 会话存储读取可靠事件、消息、输出索引、预算及资源归属
  -> 不确定状态先阻断并展示协调原因
  -> 为本次用户输入创建 task/run，装配现有 CodePilotApplication
  -> Runner 获取会话历史与本次上下文视图
  -> 权限 -> 调度 -> 后端 -> 输出分块保存 -> 配对工具结果
  -> 保存完成事实与唯一终态 -> 独立验收结果 -> 下一条用户输入
```

会话拥有历史和持久输出，Runner 仍单次使用。run 关闭 Provider/进程/容器，不删除会话仍引用的正文；会话删除和过期清理独立执行并核对引用。

## 最小内部契约和所有者

优先扩展已有契约，只在确有职责时新增模型，不为规划预建空抽象。

| 契约 | 必要字段与不变量 | 所有者 |
| --- | --- | --- |
| 会话身份 | schema_version、session/task/run、工作区身份、配置摘要、更新时间 | 会话服务；不能仅凭路径字符串静默切换仓库 |
| 持久事件 | 单调序号、事件类型、call ID、意图/开始/结果/终态、可靠提交位置 | 会话存储；写操作先持久化意图，日志与索引不假定跨介质原子 |
| 消息与事实 | 原始用户请求、完整模型消息、配对工具结果、已有压缩视图及覆盖范围、验证记录 | 私有会话存储；默认脱敏 Trace 仍不记录正文 |
| 输出引用 | artifact/call/stream、字节范围、observed/saved bytes、哈希、complete/partial/quota_exceeded | 后端分块生产，控制器私有存储保存；引用跨 run 有效 |
| 预算与保留 | 每命令/task/session 输出限额、总量预留/结算、TTL、显式删除 | 会话服务；并发不超发，未知数据不冒充完整 |
| 资源与协调 | UID、PID 启动身份/容器 ID、工作树、归属、运行状态、协调原因 | 会话服务核对；身份不匹配不能误杀或误删 |

采用 SQLite 管会话索引、消息/状态及资源归属，版本化追加事件与私有 Artifact 文件保存可核对事实和正文；写入顺序明确，索引可重建。目录私有、文件 0600，拒绝不安全符号链接；导出默认脱敏。用户正文持久化需在启动帮助与保留设置中说明，Provider 秘密不得持久化。

stdout/stderr 各自保留顺序，不承诺跨管道精确全局时序；解码是有界视图，原始字节不因 UTF-8 分块或二进制内容损坏。模型仅能按授权 ID 有界读/搜，不能访问任意宿主存储路径。

## 状态与保守重开

- 会话与 run 状态分离：旧 run 的 completed/failed/cancelled 为不可变终态，新输入创建新 run。
- 工具状态至少有 planned/running/succeeded/failed/cancelled/unknown；意图存在、结果缺失不能推断未执行。
- 正常已结束会话核验工作区和存储完整性后可继续；重开不自动执行上次未完成工具。
- running/unknown、未配对调用、意外工作区变更、资源身份异常统一进入 needs_reconciliation。CLI 显示事实与可执行的确认入口，不能让用户猜状态或盲目修改数据库。
- 协调至少支持独立检查文件/Git/进程与明确结束未知任务后创建新 run；确认只改变已核验状态，不伪造旧调用成功。审批不跨崩溃直接复用。
- 基础重开先覆盖安全、可判定路径；更复杂多崩溃点快照恢复在 B3 深化，不声称 exactly-once。

## 联合验收与重要故障

| 场景 | 独立判据 |
| --- | --- |
| 正常连续任务 | 首次读取/定位，第二次根据测试失败修改，第三次追问；控制器确认模型收到正确历史且未重复执行旧工具 |
| 退出后重开 | 新进程从私有存储读取消息、结果及同一 Artifact，继续追问；不依赖原进程内存或旧容器 |
| 大输出 | 至少 100 MiB 两路输出含中段唯一标记；每路哈希/统计核对，按 ID 读取和检索正确，控制器及 worker 峰值内存有明确上限证据 |
| 取消竞态 | 稳定复现旧 Shell 取消问题；修复后进程树退出、排队读取不启动、唯一终态，已捕获输出为 partial |
| 磁盘满或配额耗尽 | 明确 partial/quota_exceeded，不发布完整引用，不无限缓存；清理活动命令且不破坏已有会话 |
| 副作用后崩溃 | 独立进程注入退出，实际文件可能已改变但结果未提交；重开必须协调，零自动重放 |
| 存储尾部损坏/SQLite 失败 | 截断仅处理可证明未提交尾部，已确认事实不回滚重放；无法重建明确停止 |
| 工作区变化/双进程重开 | 路径/仓库身份不符先阻断；同会话只有一个写入者，锁过期不误认仍活跃所有者 |
| 非 Git/脏目录 | 用户已有差异和未跟踪文件保留，退出/重开不 reset/clean、不自动改为 worktree |
| 正常清理与保留 | 无活动受管进程/容器；历史输出保留可读，删除或过期后引用明确失效，非本任务资源不受影响 |

先完成确定性测试（包括真实子进程、磁盘故障和进程崩溃），再运行受控 Rootless Docker 验收，最后低成本真实模型验证连续追问/重开。每次真实验证先固定便宜模型、请求数上限及 Token 上限，预算不足不擅自扩大。模型自述、工具成功、Runtime 终态、独立验收分开记录。

现有验收命令：

```bash
uv run --locked pytest -q
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked mypy
uv build --wheel
CODEPILOT_DOCKER_LIVE=1 uv run --locked pytest -q tests/test_workspace_docker_live.py
```

新增会话/输出/崩溃测试与安装版 CLI 联合脚本在实现中补齐，不用旧套件通过代替新能力验收。Rootless 只使用用户 daemon，禁止修改公共 Docker。

## 实现入口与目录责任

现有 `app/service.py` 管装配；`ui/cli.py` 管统一入口；`runtime/loop.py` 管单次循环；`tools/shell.py`、`workspace/local.py`、`workspace/docker.py`、`workspace/worker.py` 共同传输输出；`context/artifacts.py`/`manager.py` 接入持久引用和有界视图。

B1 实现时新增 `src/codepilot/sessions/` 负责持久会话与协调，避免让 UI 或 Runner 直接操作数据库；测试放 tests，证据放 docs/evidence/B1-*。本轮仅写规划，没有创建这些 Python 模块。
