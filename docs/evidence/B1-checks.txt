根因与失败记录：
1. 取消：初版两个任务同时清理的屏障没有触发；改为排队任务先退出后，旧 Runtime 稳定失败。
   tests/test_scheduler.py::test_runner_does_not_interrupt_cleanup_with_a_second_cancel
   interrupted.is_set() 为 True。原因：gather 已传播取消后 Runtime 再次 cancel 活动清理。
   修复：不再次取消 cancelling()>0 的子任务；统一进程创建/回收，并等待清理真正结束。
2. 真实 Docker 大输出首次 1 failed / 5 passed：1 KiB 预览上限也截断 describe Schema。
   修复：控制协议传输预算与工具预览预算分开；增加帧顺序及原始字节/哈希核对。
3. 开发时新增测试曾因 fixture 未绑定 workspace 而未触达活跃进程判断；修正 fixture 后通过，未降低断言。
